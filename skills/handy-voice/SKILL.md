# Локальная расшифровка речи

```sh
bb handy-voice transcribe <путь-к-аудио>
```

Печатает текст расшифровки. Понимает webm, ogg, mp4/m4a, mp3, wav — всё, что
читает ffmpeg. Работает на локальной модели (GigaAM v3) через приложение Handy:
ни звук, ни текст не уходят с компьютера.

Скорость на M1 Pro: ~1 с на минуту речи.

## Когда применять

- Владелец приложил голосовую заметку или аудиофайл.
- Нужно расшифровать запись из любой папки.

`bb voice transcribe` тоже работает и тоже считает локально — задача `voice`
отдана этому плагину. Команда выше короче и не зависит от настройки.

## Служебное

```sh
bb handy-voice status   # пути к Handy и ffmpeg, выбранная модель, готовность
bb handy-voice models   # модели Handy, «+» — уже скачанные
```

Ошибка «Не нашёл Handy» — не установлено приложение Handy (handy.computer)
или сменился путь: `bb plugin config handy-voice set handyPath <путь>`.
