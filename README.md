# Handy Voice — локальная диктовка для BB

Плагин для [BB](https://getbb.app): голосовой ввод в композере считается
локальной моделью на вашем компьютере. Ни звук, ни текст никуда не уходят —
ни в bb cloud, ни к OpenAI, ни куда-либо ещё.

Два отличия от штатного микрофона BB:

- **Запись не обрывается при переходе в другой тред.** Можно начать диктовать
  в одном чате, уйти в другой, вернуться и нажать «Стоп» — текст ляжет в
  черновик того чата, где вы начали.
- **Нет потолка в 10 секунд на расшифровку.** Проверено на 5,5 минутах речи:
  5,1 секунды на расшифровку.

Скорость на MacBook Pro M1 Pro: около секунды на минуту речи.

## Требования

1. **BB** версии 0.49 или новее.
2. **[Handy](https://handy.computer)** — бесплатное приложение для диктовки с
   открытым кодом. Плагин вызывает его в headless-режиме; само окно Handy для
   работы плагина открывать не нужно.
3. Загруженная в Handy модель распознавания.

ffmpeg ставить не нужно: он приходит вместе с плагином как npm-зависимость.

Разрабатывалось и проверялось на macOS. Handy есть и под Windows с Linux —
там достаточно указать путь к бинарнику в настройке `handyPath`.

## Установка

### 1. Handy и модель

Скачайте Handy с [handy.computer](https://handy.computer), откройте его и в
настройках выберите модель:

- **русский** — GigaAM v3 (`gigaam-v3-e2e-rnnt`), он же заметно лучше Whisper
  на русском и не выдумывает титры вроде «Субтитры сделал …»;
- **английский** — Parakeet;
- **многоязычно** — Whisper Large v3 Turbo.

Дождитесь, пока модель скачается, и убедитесь, что диктовка работает в самом
Handy (по умолчанию — Option+Space). Плагин использует ту же модель, которую
вы выбрали в приложении.

### 2. Плагин

```sh
bb plugin install git:https://github.com/omiusgm/bb-plugin-handy-voice --yes
bb handy-voice status
```

`status` должен показать пути к Handy и ffmpeg и строку «готов: да».

### 3. Штатный микрофон BB

В композере будет два микрофона: наш и штатный. Выключать задачу `voice`
(`bb settings ai-services set voice off`) **не стоит**: BB всё равно рисует
свою кнопку, и она начинает падать с ошибкой «Turned off in Settings». Пусть
задача остаётся за плагином — тогда обе кнопки работают и обе считают
локально, просто штатная не переживает переход в другой тред.

Проверить, что штатный путь тоже локальный:

```sh
bb voice transcribe <файл>
```

## Как пользоваться

Кнопка микрофона в композере: нажали — пишет, нажали ещё раз — расшифровывает
и дописывает текст в конец черновика. Во время записи кнопка краснеет и
показывает таймер. Уже набранный текст сохраняется.

## Команды

```sh
bb handy-voice status              # Handy, ffmpeg, модель, готовность
bb handy-voice models              # модели Handy, «+» — уже скачанные
bb handy-voice transcribe <файл>   # расшифровать аудиофайл локально
```

`transcribe` понимает webm, ogg, mp4/m4a, mp3, wav — всё, что читает ffmpeg.

## Настройки (`bb plugin config handy-voice`)

| Ключ | По умолчанию | Смысл |
| --- | --- | --- |
| `handyPath` | `/Applications/Handy.app/Contents/MacOS/handy` | путь к бинарнику Handy |
| `model` | пусто = модель, выбранная в Handy | id модели, см. `bb handy-voice models` |
| `ffmpegPath` | пусто = ffmpeg из зависимостей плагина, затем системный | путь к ffmpeg |
| `warmOnLoad` | `true` | прогрев модели при загрузке плагина |

## Как устроено

1. Кнопка пишет звук в webm/opus через MediaRecorder.
2. Запись уходит в собственный RPC плагина — не в штатную службу BB, поэтому
   без её 10-секундного потолка.
3. Сервер конвертирует файл локальным ffmpeg в WAV 16 кГц моно.
4. Запускает `handy --transcribe-file <wav> --json` и возвращает текст.

Запись живёт в module-scope синглтоне (`lib/dictation.ts`), а не в React-
состоянии композера: размонтирование компонента снимает только подписку UI.
Ручка композера захватывается в момент старта, а черновики BB переживают уход
с экрана — поэтому текст приземляется в исходный чат. Перезагрузка окна или
плагина в этот сценарий не входит.

При загрузке плагин делает холостой прогон на полусекунде тишины, чтобы первая
диктовка не ждала чтения модели (у GigaAM v3 это 261 МБ) с диска.

Плагин также регистрирует службу `handy` для задачи `voice`, так что штатный
микрофон BB и `bb voice transcribe` тоже могут работать локально — см. шаг 3
установки.

## Ограничения

- Своё ограничение на входное аудио — 32 МиБ, таймаут ffmpeg и Handy — 10 минут.
- Handy должен быть установлен, а модель — скачана в самом Handy.
- Кнопка работает в черновиках тредов и нового треда.
- Заголовки тредов и сообщения коммитов — отдельные задачи BB
  (`thread-title`, `commit-message`), этот плагин их не трогает.

## Разработка

```sh
npm install
npx tsc --noEmit
node --test tests/dictation.test.mjs
bb plugin build .
bb plugin install . --yes
```

Автотесты проверяют главный сценарий: запись в чате A, размонтирование
композера, остановка из чата B, текст уходит в черновик A.
